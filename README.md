# Netflix Data Analysis & Power BI Dashboard

## 📊 Project Overview

This project focuses on analyzing Netflix data and presenting meaningful insights through interactive Power BI dashboards.

The project includes multiple dashboards covering content, customer, churn, and executive-level analysis.

## 🎯 Objective

- Analyze Netflix data and identify meaningful patterns
- Understand content trends
- Analyze customer-related information
- Examine churn-related patterns
- Track important KPIs
- Present insights using interactive Power BI dashboards

## 🛠️ Tools Used

- Power BI
- Microsoft Excel
- Data Analysis
- Data Visualization
- Dashboard Development

## 📈 Dashboards

- Dashboard Overview
- Content Analysis
- Customer Analysis
- Churn Analysis
- Executive Analysis
